# Components

Framework: **Vue 3** (Composition API, `<script setup>`), component library: **Vuetify 3** (Material Design based). No custom shared component library exists yet — all UI primitives (buttons, cards, file inputs, data tables, alerts, chips, app bar) come directly from Vuetify's built-in components (`v-card`, `v-btn`, `v-file-input`, `v-data-table`, `v-alert`, `v-chip`, `v-app-bar`, `v-container`).

There are currently only 2 page-level view components and no extracted reusable UI components. See `extractable-components.md` for what could be pulled out.
